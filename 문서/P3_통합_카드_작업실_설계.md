# P3 — 통합 카드 작업실 (2026-11-11)

## 목표

이제 CDB에서 추출된 카드와 Lua/이미지로만 확인되는 카드도 **자체 작업 문서**를 갖는다. 모든 테마를 카드 ID로 검색할 수 있고, 카드를 열면 원본 파일·원본 후보·수정 제안·승인 효과·검수 상태·감사 이력을 볼 수 있다.

## 데이터·출처 및 안전

- P1 《종언성서 — 녹투르나》 16개 설계 문서는 기존 `ygo_card_studio` IndexedDB에 그대로 유지한다.
- P2 테마 및 바이너리 원본과 CDB 추출 기록은 `ygo_card_studio_file_vault` IndexedDB에 그대로 유지한다.
- P3 통합 작업 문서는 별도의 `ygo_card_studio_imported_workbench` IndexedDB에 저장한다. **키는 테마 ID + 카드 ID 쌍**이며, 다른 테마의 동일한 카드 ID를 하나로 합치지 않는다.
- CDB의 효과 문자열은 **출처 자료**이며 승인된 원문이 아니다. 여러 CDB에서 같은 카드 ID의 카드명·효과가 다르면 모든 원본과 출처를 보여주고 충돌을 알린다.
- Lua는 읽기 전용으로 처음 100KB까지만 미리보며 실행·검증하지 않는다. 이미지도 승인 여부와 무관하게 *원본 후보*로 표시한다.
- 효과 원문은 `제안 등록 → 원문 비교 → 명시 승인` 경로만 변경한다. 검수 상태는 독립적이며 `검증완료/승인/통과`를 선택하면 근거를 요구한다.
- 카드 메모와 문서 상태 변경도 리비전 및 이벤트 이력에 남긴다. 다른 탭에서 같은 카드 문서를 수정했으면 IndexedDB의 버전을 확인해 덮어쓰지 않는다.
- CDB·Lua·이미지 파일을 편집하거나 덮어쓰지 않는다. 업로드된 자료와 작업 문서가 다르면 반드시 양쪽을 별도로 표시한다.

## UI 구조

1. **테마 라이브러리**: 테마별 연결 카드 목록, 카드 ID별 작업실로 이동
2. **카드 라이브러리**: 기존 《녹투르나》 설계 문서 + 전체 테마에서 추출된 파일 연결 카드 목록, 각 목록 독립 검색
3. **파일 센터**: CDB 카드 인덱스/카드 ID별 Lua·이미지 연결을 클릭해 카드 작업실로 이동
4. **통합 카드 작업실**: 좌측 일러스트 원본과 카드 식별/설계 메모, 중앙 승인 원문·출처·제안 및 Lua 코드, 우측 OCG·밸런스·CDB·Lua·EDOPro 검수
5. **백업·설정**: 《녹투르나》 설계 백업과 P3 작업 문서 백업을 분리 제공 (복원 가능)

## 의도적으로 남긴 한계

- 기존 아벨 16종은 EDOPro 카드 ID가 확인되지 않아 자동으로 CDB 파일에 연결하지 않는다. 향후 명시적 카드 ID 지정 및 충돌 확인 뒤 통합.
- 외부 테마 작업용 카드명은 확정 카드명을 자동 승인하지 않는다. CDB 카드명도 출처 후보.
- 바이너리 원본은 JSON 백업에 포함되지 않는다. 별도로 원본 ZIP 및 GitHub 카드 자료를 보관해야 한다.
- 실전 EDOPro 테스트 결과는 자동 생성하지 않는다. Lua 검증·배포는 P4/P6에서 다룬다.
- IndexedDB를 사용하는 브라우저/기기가 다르면 개별 데이터 복원이 필요하고 자동 클라우드 동기화는 없다.
