# YGO STUDIO V2.3 — 전체 화면 작업실 전환

## 목적

사용자가 YGO STUDIO에서 도구 메뉴를 선택하면 **메인 사이트의 왼쪽 사이드바, 상단 검색바, 소개 배너, 커다란 작업실 컨테이너를 숨기고** 선택한 도구의 원래 편집 화면을 브라우저 전체 너비로 표시한다. 별도 탭이나 사이트 주소 이동 없이 작업하며, 상단의 작은 **스튜디오로 돌아가기** 버튼으로 직전 화면에 복귀한다.

## 구현 범위

| 메뉴 | 실제 화면 | 구현 방식 | 기존 데이터 |
|---|---|---|---|
| 카드 렌더러 | DUELMIND 원래 헤더·테마 목록·3열 편집 화면·출력 컨트롤 | 현재 페이지 안 React + ShadowRoot 네이티브 (iframe 없음) | 기존 IndexedDB 유지 |
| 이미지 연구소 | ART LAB 원래 헤더·카드 목록·생성/미리보기·출력·라이선스 푸터 | 현재 페이지 안 원본 엔진 + ShadowRoot 네이티브 (iframe 없음) | 기존 localStorage 유지 |
| 디자인·덱 실험실 | 기존 DESIGN LAB 전체 화면 | 같은 출처의 전체 화면 iframe (네이티브 이식은 **아직 아님**) | 기존 저장소 유지 |
| PSH 검증 관제실 | 기존 관제실 전체 화면 | 같은 출처의 전체 화면 iframe (네이티브 이식은 **아직 아님**) | 기존 기록 유지 |

- 전체 화면 라우트: `src/App.tsx`의 `isFullscreenPage` 분기.
- 공통 외곽 및 복귀 버튼: `src/fullscreen-workspace.css`.
- 네이티브 전환: `src/NativeWorkspace.tsx`의 `fullscreen` 옵션.
- 도구별 작업 화면의 주요 UI는 변경하지 않고, 접속할 때 표시되는 **YGO STUDIO의 중복 테두리/소개/메뉴**를 없앴다.
- 공통 카드 ID 전달이 대기 중이면 도구 위쪽에 **명시 승인 안내**가 나타난다. 기존 카드는 덮어쓰지 않는다.
- 이미지 연구소의 오픈 SVG 라이선스 표시는 원본 푸터를 유지하며, URL은 통합 사이트의 올바른 경로로 보정한다.
- 뒤로가기 버튼은 현재 브라우저 탭에서 이전 스튜디오 화면으로 돌아오는 기능이다. 브라우저 자체 뒤로가기와 영구 URL 라우팅은 이 단계에서 변경하지 않았다.

## 검수

- 기존 CARD STUDIO 타입 검사·단위 테스트·회귀 E2E 통과 여부.
- Chromium 통합에서 각 도구의 전체 화면 경계가 뷰포트 너비와 일치하는지, 상위 YGO STUDIO 메뉴가 제거되는지 검사.
- 카드 렌더러의 토큰/크롭 조작과 이미지 연구소의 캔버스·원래 상단 브랜드·라이선스 푸터 복원.
- 다른 도구에서 들어온 뒤 해당 화면으로 복귀하는지 확인.
- 기존 공통 카드·덱 보관함→제작 도구 전송 및 중복 보호.
- DESIGN LAB·PSH는 기존 iframe을 제거하지 않았으므로 ‘완전한 네이티브 포팅’으로 표시하지 않는다.

## 다음 단계

V2.4는 DESIGN LAB과 PSH 관제실의 네이티브 이식 가능성 및 실제 데이터 연동을 검토한다. 사용자 데이터를 PC에 백업하고 구형 사이트·저장소별 복원 기능을 확인하기 전에는 독립 사이트를 폐쇄하지 않는다.
