# YGO STUDIO V2.8 — 공통 카드·덱·일러스트 연결 검수

## 목표
V2.7에서 구축한 카드 ID 기반 보관함 및 공통 이미지 Blob 데이터를 **YDK 덱의 각 카드와 연결해 검토**할 수 있도록 한다. 카드 데이터를 자동 덮어쓰거나 CDB/Lua/EDOPro 엔진을 수정하지 않는다.

## 기능
- **덱 진단:** 저장된 YDK의 메인/엑스트라/사이드별 카드명을 숫자 카드 ID로 대조한다. 같은 카드가 여러 장이면 카드 수는 *매수 기준*, 누락 ID 목록은 *고유 ID 기준*으로 계산한다.
- **공통 일러스트 연결:** 공통 이미지 보관함의 카드 ID와 연결한다. 덱 영역별로 이미지를 미리보며 원본 Blob은 변경하지 않는다.
- **효과 텍스트 조회:** 공통 카드 원장에 저장된 카드명·테마·효과 텍스트를 접어서 확인한다. 이는 **OCG 효과 승인 또는 Lua 구현 성공 판정이 아니다.**
- **누락 카드 식별:** 공통 카드 원장에서 찾지 못한 카드 ID를 고유 목록으로 제시하고 TXT로 내보낸다. **EDOPro에 없는 카드**라는 뜻이 아니다.
- **동기 UI:** 현재 통합 카드 렌더러에서 신규 이미지 연결을 승인하면 덱의 이미지 연결 수가 페이지 새로고침 없이 갱신된다.
- **ID 및 버전 호환:** 카드 렌더러와 공통 이미지 IndexedDB를 특정 이전 버전(1)으로 강제하지 않고 현재 버전으로 읽는다.

## 보존 정책
1. 덱 진단 및 이미지 조회에서는 IndexedDB·localStorage를 변경하지 않는다.
2. 기존 이미지 연결 기능은 **신규 ID만 add** 하며 같은 ID 원본은 덮어쓰지 않는다.
3. YDK 내 카드 매수와 영역 순서는 고치지 않는다. 다운로드한 YDK도 기존 저장 구성을 유지한다.
4. 통합 ZIP 백업(V2.7.1), CDB·Lua·PSH 기록·기존 독립 사이트는 변경하지 않는다.
5. 대체 Origin(다른 URL 또는 localhost)은 브라우저 보안상 자동 수집하지 않는다.

## 검증
- 단위 테스트: 영역 순서·복수 매수, 카드명/이미지 연결 수, 고유 누락 ID, 이미지가 있는데 카드명은 없는 경우, 읽기 전용.
- Chromium 통합 테스트: 저장된 YDK와 공통 이미지 Blob의 결합·누락 ID TXT 파일·기존 localStorage 보존.
- Chromium 통합 테스트: 버전 3의 카드 렌더러 IndexedDB에서 이미지를 신규 연결하고, 덱 상세의 이미지 수 자동 갱신.
- 기존 단위·타입·UI·네이티브 모듈 전체 회귀를 병합 조건으로 유지.

## 다음 단계
읽기 전용 연결이 안정화되면, 사용자 승인에 따른 특정 덱의 누락 카드만 원본 보관함에서 가져오는 선택적 매핑 기능을 검토한다. 원본 충돌 검토·승인 정보는 별도 취급한다.
