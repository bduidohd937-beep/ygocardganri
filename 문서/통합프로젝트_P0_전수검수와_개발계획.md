# YGO STUDIO 통합 계획 P0 — 7개 저장소 검수 및 설계

검수 기준: 2026-11-12 (KST). **이 문서는 통합 설계안이며, 기능 이식·데이터 이전·실제 통합 테스트 완료를 뜻하지 않는다.**

## 1. 결론

- **통합 웹 본체**: `ygocardganri`의 React 19 / TypeScript / Vite 구성과 기존 카드·덱·검수 UI를 유지한다.
- **소스 보존**: 기존 7개 저장소의 `main` 및 개발 브랜치, 사용자 파일, 브라우저 저장소를 변경하지 않는다.
- **통합 UX**: 동일 GitHub Pages 웹사이트에서 카드 관리 → 임시 일러스트 → 카드 프레임 출력 → 덱 분석/수정 → 검증 관제까지 이동하게 한다. **외부 페이지 링크 모음만으로 최종 통합 완료를 선언하지 않는다.**
- **공통 데이터**: 카드 ID(문자열로 취급), 테마/출처, 덱의 원본 지문, 검증 버전 및 근거와 상태를 분리한다. 승인되지 않은 근거·실전 결과는 ‘미확인’으로 유지한다.
- **실제 EDOPro 실행**: 정적 GitHub Pages 범위 밖. 로컬 서버/브리지로 별도 구현·검수하고, `ygo` 비공개 소스나 EDOPro 설치 자산을 웹 공개 배포에 포함하지 않는다.

## 4. 목표 메뉴와 기능

1. **대시보드**: 최근 프로젝트/테마/덱/미해결 결함 요약. 실제 동기화되지 않은 데이터는 '미연결' 배지.
2. **테마·카드 작업실**: 기존 CARD STUDIO 유지, 원문·승인·버전 관리.
3. **이미지 연구소**: ART LAB의 임시 일러스트 생성과 ZIP 내보내기.
4. **카드 렌더러**: CARD MAKER의 카드 프레임/펜듈럼/링크/마법·함정 출력.
5. **덱 연구소**: CARD STUDIO P5·P6 + DESIGN LAB의 고급 실제 덱 매수 편집, YDK 내보내기.
6. **오류·검수**: CDB↔Lua 정적 검수, 수동 실전 기록 및 근거별 분리.
7. **AI 대전·검증 관제**: PSH 세션/MSG16 P0/로그 파일/주간 3대 과제. 실제 듀얼 실행과 분리.
8. **원본·백업 센터**: CDB/Lua/YDK/이미지 원본 참조·SHA256·백업·이전 도구.

## 6. 마이그레이션 원칙

- 기존 페이지의 `localStorage`/`IndexedDB`는 **origin별 분리**다. HTML 파일에서 새 GitHub Pages 사이트로 이동하거나 독립된 웹 주소를 하나로 합쳐도 저장 기록이 자동 복제되지 않는다.
- 백업 종류가 다르다: CARD STUDIO JSON은 바이너리 파일을 포함하지 않을 수 있고, CARD MAKER JSON은 카드 이미지 포함이 가능하며, DESIGN LAB 파일 자료실은 별도 IndexedDB, PSH는 별도 localStorage, ART LAB도 별도 키를 사용한다.
- **업로드되지 않은 파일/증거는 미확인**, 승인 없는 자동 덮어쓰기·승패 추정은 금지.
- 저장공간·용량 제한, 파일별 해시, 복원 전후 건수, 원본 스냅샷, 실패 시 롤백을 테스트한다.
- 새 코드 배포는 기존 사용자 저장 기록과 별개이며, 기존 URL에서 JSON 백업을 받도록 안내한다.
