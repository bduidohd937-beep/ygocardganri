# YGO STUDIO V2.5 — DESIGN LAB 네이티브 작업실 검수

## 변경 범위

- 기존 YU-GI-OH-DESIGN-LAB 카드 자료실, 원문·CDB·Lua 교차 검수, 덱 연구소를 YGO STUDIO 전체 화면 안에서 **iframe 없이 실행**하도록 변경.
- 기존 DESIGN LAB 전체 기능 코드를 새로 작성하는 대신 GitHub 고정 스냅샷의 원본 ES 모듈을 esbuild로 묶어, 문서 조회와 창 이벤트만 ShadowRoot 영역으로 격리.
- 원본 UI 구성, 탐색 탭, 파일 업로드, 원문 목록, CDB/Lua 정적 검사, 덱 조합 분석 및 보고서 내보내기를 보존.
- 파일 자료실 IndexedDB 키 `유희왕_DESIGN_LAB_자료실`, 덱 조건 키 `design-lab:deck-openers:v1` 및 기존 UI 설정 키를 변경하지 않음.
- 원본 YDK·CDB·Lua 파일을 자동 설치하거나 실전 검증 완료로 표시하지 않음.
- DESIGN LAB의 SQL 파서는 통합 사이트에서 검증된 `sql.js`를 사용하며 WASM 파일을 현재 GitHub Pages 앱에 함께 패키징. ZIP 처리는 기존 `jszip` 사용.
- 원본 DESIGN LAB 단독 사이트와 원본 GitHub 저장소를 유지하며 사용자 데이터 삭제/자동 이동은 수행하지 않음.

## 검증 기준

- 원본 DESIGN LAB의 Node.js 단위 테스트 전부 통과.
- YGO STUDIO 타입·단위·기존 전체 회귀 E2E 통과.
- Chromium 새 통합 테스트: 네이티브 DOM 존재, iframe 0개, 카드 자료실/원문 검수/덱 연구 탭 전환, YDK 파일 가져오기와 저장, 스튜디오 복귀 후 재입장해 파일 복원.
- 주소창 URL을 연구 도구의 해시 변경으로 바꾸지 않도록 별도 가상 location/history 사용.
- 메뉴/다이얼로그 CSS는 ShadowRoot 내부로 제한하며 카드 원문·덱 자료는 변경하지 않음.

## 후속

- PSH 관제실은 V2.5에서 **기존 전체 화면 iframe 유지**. 웹에서 로컬 EDOPro 엔진 직접 실행했다고 주장하지 않음.
- 카드 원본/이미지/덱의 전면 양방향 동기화와 로컬 프레임 ZIP 이전은 별도 단계. 사용자가 로컬 자료 이전을 미루기로 했으므로 이번 패치에서 변경하지 않음.
- 디자인 통일은 원본 도구를 보존하는 범위에서 계속 개선하며 사용자별 데이터 내보내기·실제 복원 검사 이전에는 구형 사이트 폐쇄 금지.
