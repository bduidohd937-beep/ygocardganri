# YGO CARD STUDIO — C안 디자인 시스템 V1.0

승인 기준: 카드 아트 갤러리 × 전문 카드 개발 워크벤치. 화면 역할에 따라 밀도를 차별화하고 가짜 통계·과도한 글로우·화려한 그라데이션을 지양합니다.

## 컬러
- 기본 배경 `#0D1014`
- 작업 패널 `#171C23`
- 구분선 `#303843`
- 주요 텍스트 `#EDEAE3`
- 주요 강조 `#A65B59`
- 검증/통과 `#729B91`

월드별 색상은 세계 구분용 얇은 강조선·라벨에만 사용합니다. 카드 일러스트에 임의 색상 필터를 적용하지 않습니다.

## 타이포그래피
- 본문 및 UI: Pretendard/시스템 산세리프, 12~14px
- 프로젝트·세계관 제목: Noto Serif KR, 22~36px
- 코드·버전·인덱스: DM Mono (추후 JetBrains Mono 선택 가능), 10~13px

## 레이아웃
- 데스크톱: 왼쪽 내비게이션(246px), 상단 검색/백업 바, 반응형 콘텐츠 영역
- 프로젝트 허브: 대표 프로젝트(원문 중심), 다섯 세계 타일, 실제 데이터로 계산한 지표와 작업 대기열
- 카드 스튜디오: 왼쪽 카드 이미지·스탯, 가운데 효과 원문·미승인 제안, 오른쪽 OCG/밸런스/Lua/EDOPro 검수
- 태블릿: 오른쪽 인스펙터가 아래 줄로 이동
- 모바일: 사이드바 드로어, 단일 열 카드 작업실
- 간격 8px 기반, 모서리 3~5px, 의미 없는 장식 지양

## 상태 규칙
- 미확인: 중성 회색
- 검토중/초안: 황갈색
- 승인/검증완료: 저채도 청록색
- 반려/충돌 확인: 연한 적갈색

디자인 상태는 실제 데이터와 연결하며, 미확인 상태를 자동으로 완료 처리하지 않습니다.

## 현재 제품의 한계

실제 이미지 업로드, CDB/Lua 검사, YDK 덱 분석은 각각 후속 단계입니다. 해당 메뉴의 '준비 중' 설명은 동작하는 버튼을 가장하지 않습니다. 승인된 기존 일러스트 자산이 전달되지 않아 아트 슬롯은 중립적 '미첨부' 플레이스홀더입니다.
