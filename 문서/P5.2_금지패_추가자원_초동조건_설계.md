# P5.2 — 금지 패 및 별도 자원 조건이 있는 조합 초동

## 사용
- **덱 연구실 → 저장할 분석안 생성 → 조합 초동 분석기**에서 A 그룹, 선택 B 그룹을 입력한다.
- 루트마다 **금지 패 그룹**(첫 패에 1장이라도 있으면 그 루트가 실패)과 **추가 자원 카드 ID 그룹**을 입력할 수 있다.
- **필수 자원 최소 매수**는 0/1/2/3장이다. 같은 ID의 복수 카드가 실물로 여러 장 있으면 복수 자원으로 센다.
- **추가 자원 그룹은 A/B 그룹과 카드 ID가 겹치면 안 된다.** 따라서 실제 A/B 카드와는 다른 실물 카드로 추가 자원을 요구한다. 별도 카드라는 모델의 의미를 명확하게 보장하기 위한 제한이다.
- 다른 루트는 별도로 판단한다. 한 루트에서 금지된 카드가 다른 루트의 초동일 수 있고, OR 합집합은 중복 없이 정확하게 계산한다.
- 기존 P5.1의 **전체 말림 위험 그룹**과 원본 YDK 대비 차이 계산, 5·6장 패 비교는 그대로 유지한다.
- **조건 적용**은 해당 루트의 모든 입력(기존 A/B + 금지/자원)을 반영한다. 저장된 덱 연구안을 수정하는 것이며 원본 YDK를 고치지 않는다.

## 계산 범위 및 알고리즘
- 메인 덱 60장 이하, 첫 패 5장 또는 6장, 최대 4개 OR 루트를 계산한다.
- 각 실제 카드 복사본을 별개로 취급하고 가능한 모든 unordered hand의 정확한 조합 가중치를 계산한다. 균등한 셔플과 비복원 추출을 가정한다.
- 기존 조건만 있으면 **P5.1 고속 DP**를 유지한다.
- 신규 조건이 있으면 **분리 Web Worker**에서 sparse dynamic programming을 수행한다.
  - 각 루트에 A 탐지, B 탐지, 별도 A/B 2장 탐지, 금지 카드 탐지, 추가 자원 수(0~3으로 포화)를 기록한다.
  - 위험 카드 탐지 비트도 함께 기록한다.
  - 개별 카드에 대해 뽑지 않음/뽑음의 조합 수를 축적한다. 조합 가중치 총합이 C(N,h)와 일치하지 않으면 결과를 공개하지 않는다.
  - 고급 조합 상태가 안전 한도를 초과하면 추정치로 대신하지 않고 **계산 상한 초과**로 안내한다.
  - 조건이나 초기 패 장수가 바뀌면 이전 Worker를 종료해 결과 혼선을 막는다.
- 단일 루트 확률의 합과 OR 합집합 확률은 일반적으로 다르다.
- 성공과 위험은 교집합으로 계산되며, 성공·위험 유무의 분할 합은 전체 확률과 일치한다.

## 백업 호환성과 보안
- 기존 P5/P5.1 분석안의 schemaVersion 1은 변경하지 않는다.
- P5.2에서 루트별 선택 필드 `forbiddenIds`, `resourceIds`, `minResources`만 추가한다.
- 기존 JSON 백업에 이 필드가 없어도 복원할 수 있다.
- 카드명이나 효과 텍스트만으로 역할을 자동 지정하지 않는다.
- 기존 업로드 YDK/CDB/Lua/이미지 원본, 카드 승인 효과, CDB 파일은 변경하지 않는다.
- 실제 효과 발동, 서치, 드로우, 소환 제약, 카드 처리 실행, 턴당 횟수 제한, 상대 대응 또는 게임 결과를 계산하지 않는다.

## 검증
- 40장 및 60장, 5·6장 패, 금지 그룹의 영향, A+B와 별도 자원의 독립성, 위험 그룹 동시 등장 검증.
- 8~10장 소형 덱에 대해서 모든 실물 카드 패의 조합을 직접 열거하는 브루트포스 계산과 비교한다.
- Chrome E2E에서 YDK 업로드 → 루트별 금지 패 / 자원 최소 매수 지정 → 부적절한 중복 자원 차단 → 저장·새로고침 → 원본 YDK 미변경 확인.
- P0~P5.1 기존 회귀 테스트, 타입 검사, 번들 예산, GitHub Pages 배포 결과를 함께 검증한다.
