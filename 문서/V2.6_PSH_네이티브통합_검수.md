# YGO STUDIO V2.6 — PSH 검증 관제실 네이티브 통합 검수

## 목표 및 변경 범위

- YGO STUDIO의 PSH 검증 관제실을 기존 전체 화면 iframe 방식에서 **현재 사이트의 Shadow DOM 네이티브 화면**으로 전환한다.
- PSH 원본 저장소 `PSH-AI-ARENA` 커밋 `1e22f657f4b9be08771953fb686a06f56a8faf9c`의 단일 HTML 원본에서 스타일/화면/스크립트를 그대로 추출한다.
- 빌드 스크립트 `scripts/build-native-arena.mjs`가 `native-arena.html`, `native-arena.css`, `native-arena.js`를 생성한다. 기존 독립 앱 `index.html`도 그대로 패키징해 보존한다.
- `src/NativeArena.tsx`가 원본 스크립트의 `document.getElementById`와 이벤트를 ShadowRoot 내부로 한정한다. 메인 YGO STUDIO DOM 및 스타일에 영향을 주지 않는다.
- 기존 `psh-ai-arena-control-v1` localStorage 키/데이터 구조를 변경하지 않으므로 같은 github.io 출처에서 이전 관제실 기록이 유지된다.
- 세션·기능·실대전 증거·회귀 테스트·결함·원본 보호·주간 우선순위·로그/MSG16·출력 수동 연동 등 기존 탭과 JSON/CSV 백업 동작을 보존한다.

## 안전 조건

- UI·수동 출력 로그 분석만 합친 것이다. 브라우저가 로컬 PSH 엔진, EDOPro, CDB 및 Lua를 직접 실행하거나 수정하는 것은 아니다.
- `ISSUE-001` MSG16 이후 교착 상태는 해결 처리하지 않는다. V2.4 세션 목표 2/완료 0 경기를 승패 데이터로 임의 변환하지 않는다.
- 원본 검증 보고와 현재 통합 브라우저 UI 테스트는 별도 증거다. 소스 원본/실행파일의 SHA-256 변경 전후 보호 실증도 별도 검사 항목이다.
- 데이터 삭제/가공 없이 기존 로컬스토리지 키를 재사용한다. 원본 PSH 독립 사이트 및 코드 저장소는 폐쇄하지 않는다.

## 배포 게이트

1. YGO STUDIO 타입 검사, 단위 및 회귀 테스트.
2. 고정된 카드 메이커·DESIGN LAB·이미지 연구소 테스트 및 기존 통합 Chromium 검사.
3. PSH 기본 대시보드, 세션/결함/로그 화면 전환, iframe 0개, 브라우저 오류 없음.
4. PSH JSON 다운로드 파일의 스키마와 `ISSUE-001`, 0/2 세션 값 확인.
5. 기록 저장 후 스튜디오 복귀/재입장에 기존 `psh-ai-arena-control-v1` 보존 확인.
6. GitHub Pages 실제 배포 성공.
