# P5.1 — 조합 초동 분석 및 검수 기준

## 핵심 모델
- **A 그룹 단독 루트:** A에 속하는 카드 1장 이상을 첫 패에 잡으면 충족한다.
- **A+B 루트:** A에 속하는 카드 한 장과 B에 속하는 카드 한 장을 **서로 다른 실제 카드 2장**으로 잡아야 한다. A와 B가 같은 ID를 포함하거나 완전히 같더라도 **동일한 실물 1장**으로 두 조건을 충족할 수 없다.
- **OR:** 최대 4개의 루트 가운데 하나 이상을 충족하면 성공이다. 루트의 확률을 더하지 않으며, 같은 패가 여러 루트를 충족해도 한 번만 센다.
- **위험 카드:** 지정한 카드 ID 그룹의 카드가 최소 1장 잡히는 사건이다. 루트 성공/실패와 위험 동반 여부를 함께 구분한다.
- 각 그룹은 사용자 지정 **카드 ID 목록**이며 한 그룹 내 ID는 OR 관계이다. 기존 P5의 수동 역할 태그를 위험 그룹에 복사할 수 있다.
- 출발 YDK의 메인/엑스트라/사이드, 승인 효과, Lua, CDB는 변경하지 않는다.

## 계산 방법
- 메인 덱에 있는 카드 **실물 복사본 각각**을 하나의 표본으로 취급한다. 메인 덱 60장 이하, 첫 패 5장 또는 6장인 경우를 계산한다.
- 카드는 복원하지 않고 균등 무작위로 패를 추출한다.
- 순서와 무관한 표본 공간 크기는 조합수 C(N,h)이다.
- 동적 계획법은 덱 복사본을 한 장씩 순회하며 '뽑음/뽑지 않음'의 조합 가중치를 기록한다. 카드 ID가 여러 장인 경우도 서로 다른 실물 복사본으로 구분한다.
- 각 루트에는 A 관측/B 관측/동일 그룹에서 다른 실물 두 번째 카드 관측의 상태 비트를 사용한다. 이 상태로 A+B의 서로 다른 카드 2장 규칙을 강제한다.
- 별도로 위험 그룹 관측 비트를 기록해 루트 성공과 위험의 교집합, 루트 실패와 위험의 교집합을 계산한다.
- 최대 4루트, 60장, 패 5/6장으로 계산 상태를 제한하고, Worker 추가 로딩 없이 정적 클라이언트 계산으로 처리한다.
- 0개의 루트가 있거나 덱 장수가 부족하면 '계산 미설정'을 표시한다. 위험 카드 그룹을 지정하지 않으면 위험 동반 확률은 미표시한다.
- **개별 루트 확률의 합계는 전체 OR 성공률과 다를 수 있다.**

## 원본 대비 분석
- 현재 분석안과 그 분석안의 원본 YDK를 **같은 조합 조건**으로 계산해 확률 변화(%p)를 표시한다.
- ID가 메인 덱에 존재하지 않으면 카드를 추정하지 않고 해당 ID가 계산에 기여하지 않음을 알린다.
- A/B ID와 말림 ID는 사용자 지정 값이다. 원본 텍스트, 실제 발동 가능 조건, 코스트·대상·소환 제한, 서치·드로우, 상대 패트랩, 금제, EDOPro 실제 전개는 반영하지 않는다.
- 이 분석 결과는 **전개 가능한 초기 패의 이론상 구성 확률**일 뿐 실제 초동 성공률이나 승률이 아니다.

## 데이터 및 이전 버전 호환
- 기존 P5 분석안의 schemaVersion 1은 유지하며, 조합 설정을 선택 필드 `combinations`로 추가한다.
- 기존 P5 저장 데이터와 JSON 백업은 이 필드가 없더라도 유효하다. 신규 저장은 별도 IndexedDB의 리비전 비교를 거친다.
- 기존 P1~P4.3 및 원본 YDK/CDB/Lua/이미지 원본은 변경하지 않는다.

## 자동 검증
- 서로 다른 실제 2장 조건, 완전히 겹치는 A/B 그룹, 동일 루트 OR 중복 제거, 말림과 성공·실패 교집합 수학 항등식 테스트.
- 8장 예제에서 가능한 모든 첫 패 조합을 열거한 **브루트포스 정답과 일치**하는지 검증.
- 40장과 60장, 패 5장/6장, 과거 P5 저장 포맷 복원 가능성 확인.
- Chrome 테스트: YDK 가져오기 → A+B 및 OR 루트 구성 → 위험 카드 지정 → 저장 → 새로고침 후 유지 → 원본 YDK 40장 보존.
