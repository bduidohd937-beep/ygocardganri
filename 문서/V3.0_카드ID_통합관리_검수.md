# YGO STUDIO V3.0 — 카드 ID 통합 관리 허브

## 기능 범위
공통 카드 원장(localStorage), 공통 이미지 저장소(IndexedDB), 파일 센터(CDB 추출 미승인 효과 원문 / Lua 원본 / 이미지 원본 / YDK), 공통 YDK를 **숫자 카드 ID(1~4294967295)** 하나로 조회한다. 기존 데이터 복사나 스키마 마이그레이션을 요구하지 않는다.

### 사용 방법
1. YGO STUDIO → 공통 카드·덱 보관함 → 05 · V3.0 카드 ID 통합 관리.
2. 카드 ID 또는 이름으로 검색하고 전체/누락/충돌/덱 사용/4종 자료 연결을 필터링한다.
3. 행의 ID를 누르면 공유 카드 원문, CDB에서 추출된 **미승인** 효과 문구와 출처, Lua 파일과 SHA, 공통/파일 센터 이미지, YDK 메인/엑스트라/사이드 매수를 확인한다.
4. CDB/Lua 자료가 없다면 파일 센터에서 CDB · Lua · 이미지 등록으로 이동해 기존 안전 가져오기 기능을 사용한다. 복귀하면 인덱스가 새로 구축된다.
5. 현재 검색 결과 CSV 내보내기로 필터링된 ID 전체의 상태표를 내려받는다. 파일명: 통합카드_ID별_연결진단_V3.0.csv

## 연결 상태의 의미
- 4/4 = 공통 카드 원장, 공통 또는 파일 센터 이미지, 파일 센터 CDB 원문, 파일 센터 Lua 원본 네 종류의 존재를 뜻한다.
- 4/4는 OCG 효과 승인, CDB 카드 구현 확인, Lua 정상 실행, 실전 검증 완료를 절대로 의미하지 않는다.
- 공통 카드 효과와 CDB 원문이 다르면 카드 원문 불일치, CDB 원본끼리 다르면 CDB 원문 충돌을 표시한다.
- 같은 ID의 Lua/이미지 파일이 복수이고 SHA가 다르면 파일 버전 충돌을 표시한다.
- ID가 같더라도 파일 센터 원본의 테마 출처를 유지하고, 기존 자료를 삭제하거나 병합해 덮어쓰지 않는다.

## 안전성
- 기존 카드·프레임·원화·YDK·CDB·Lua·검수 상태 및 PSH 대전 기록을 수정하지 않는다.
- 카드명/효과가 다른 CDB 원문은 자동 수정하지 않는다. 미승인 출처로 나란히 표시하고 기존 검수 화면으로 연결한다.
- Lua 스크립트를 실행하지 않는다. 파일 센터의 기존 정적 분석 메모만 표시한다.
- 사용자의 다른 origin(로컬 127.0.0.1:5173, 독립 GitHub Pages) 브라우저 저장소에 직접 접근하지 않는다. 현재 YGO STUDIO origin으로 이미 가져온 자료만 연결한다.
- 파일 센터 데이터가 손상되면 통합 조회를 차단하며 자동으로 빈 자료로 덮어쓰지 않는다.
- CSV 출력 시 수식 실행을 유발할 수 있는 문구의 선두 =, +, -, @ 문자에는 접두부를 붙여 무력화한다.
- 표는 성능 보호를 위해 150종까지만 표시하지만 통계와 CSV는 해당 필터의 전체 검색 결과를 사용한다.

## 검증
- 순수 모델: 5개 원본의 ID 결합, 원본 불변, 해시·CDB 충돌, 파일만 있는 카드, 무효 ID, 카드 필터, CSV 수식 방어.
- Chromium 통합: 실제 IndexedDB+localStorage에 데이터를 넣어 통합 조회, 효과/이미지/덱 수량 확인, CSV 다운로드, 원본 불변 및 파일 센터로 이동.
- 기존 V2.8/V2.9 회귀, 전체 CSS 27KiB 및 초기 JS 150KiB 한도를 적용한다.
