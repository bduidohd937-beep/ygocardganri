# YGO STUDIO P2 — 공통 카드·덱 메타보관함과 안전한 전달

기준: 2026-11-12. **이 문서는 P2 1차 범위이며 모든 도구의 완전한 데이터 동기화/이전 완료를 뜻하지 않는다.**

## 사용법

1. YGO STUDIO → **공통 카드·덱 보관함**.
2. 카드 ID가 포함된 **JSON(카드 배열 또는 cards[]), CSV(id,name 헤더 필수), YDK**를 선택한다. 또는 공통 카드 ID/이름을 직접 입력한다.
3. **미리보기 → 새 카드 수·중복·충돌 확인 → 신규만 확정**을 눌러 저장한다.
4. 선택한 카드에 체크하고 **이미지 연구소** 또는 **카드 렌더러** 전송을 누른다.
5. 대상 작업실에 나온 **선택 카드 신규만 가져오기** 버튼을 사용자가 직접 승인한다.
6. 대상 앱의 카드 목록에 실제 카드가 반영됐는지 확인한다.

## 저장/동기화 범위

| 자산 | P2 1차 결과 | 이유 |
|---|---|---|
| 공통 카드 ID·이름·테마·효과 메타 | 저장 및 JSON 백업 | 별도 localStorage `ygo-studio-shared-catalog-v1` |
| 숫자 카드 ID | 문자열로 정규화 | CARD STUDIO 내부 world/phase 키는 자동 숫자 ID가 아니다 |
| YDK 메인·엑스트라·사이드 카드 구성 | 정적 해석·보관·재출력 | 효과/금제/승률 계산 기능 아님 |
| 동일 ID 원문 충돌 | **기존 자료 보존, 충돌 건수 표시** | 자동 덮어쓰기 금지 |
| ART LAB 카드 목록 | 동일 사이트에 보존된 카드 메타 읽기 | 기존 외부 사이트 origin의 데이터는 볼 수 없음 |
| 카드 렌더러 현재 프로젝트 | 같은 사이트 IndexedDB에서 읽기 전용 검토 | 신규 카드 전달 시 기존 ID 제외 |
| 카드 렌더러 속성·종족·프레임·스탯 | **미확인 / 임시값으로 분류** | 자동 확정하지 않음, 검수 후 출력 |
| 카드 원본 CDB/Lua·EDOPro 설치·실전 승패 | **미연동 / 수정 없음** | 실제 엔진 실행 및 원본 파일 접근과 분리 |
| ART LAB 생성된 이미지·CARD MAKER 렌더 결과 | **자동 역전송 미구현** | 이미지 파일은 기존 ZIP/JSON으로 별도 보관 |

## 저장 공간

- 공통 카드/덱 메타는 통합 웹사이트의 `localStorage`에 별도 저장한다.
- 큰 이미지 바이너리는 공통 메타 백업에 포함하지 않는다.
- 현재 최대 카드 2000장, 덱 200개, 업로드 3MiB, 일회 전송 400장이다.
- 이미 존재하는 공통 저장 자료가 손상되면 임의로 초기화하지 않고 쓰기를 차단한다. 원본을 별도로 백업·검토한다.

## 기존 사이트별 자료 이전

- **CARD MAKER**: 기존 사이트에서 전체 JSON 백업을 받고, 통합 사이트 **카드 렌더러에서 먼저 가져오기**를 한다. 이미지가 포함된 원본 JSON은 공통 카드 메타 자료실의 3MiB 한도를 초과할 수 있으므로 해당 자료실로 직접 대체하지 않는다. 이후 공통 카드 자료실의 ‘통합 카드 렌더러 카드 읽기’ 사용.
- **ART LAB**: 기존 사이트의 localStorage는 새 통합 사이트로 자동 이동하지 않는다. CDB/CSV/TXT에서 카드 목록을 다시 불러오고 기존 다운로드 이미지 ZIP은 별도로 보관한다. 프리셋/개별 스타일의 자동 이전은 미구현.
- **DESIGN LAB**: 원본 자료실의 IndexedDB 파일과 수동 검수 JSON 백업은 별도 관리. 공통 메타 자료실이 해당 원본과 승인 기록을 대신하지 않는다.
- **PSH 관제실**: 수동 세션·검증 로그는 자체 JSON으로 백업/복원. P2 공통 카드 메타가 실전 성공으로 승격되지 않는다.
- **CARD STUDIO**: 현재 world/phase 내부 카드 키(예: `blood-0`)는 OCG 숫자 카드 ID가 아니다. 확정 CDB/외부 카드를 통해 해당 ID를 알기 전에는 자동 연결하지 않는다.
- **EDOPro·CDB·Lua 원본**: 어떤 파일도 직접 덮어쓰거나 자동 설치하지 않는다. `ygocustome` 및 비공개 `ygo` 저장소 유지.
