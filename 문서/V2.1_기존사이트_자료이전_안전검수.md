# YGO STUDIO V2.1 — 기존 사이트 자료 이전 센터

> 적용 범위: GitHub Pages에 설치된 통합 스튜디오의 **사용자 선택 파일** 및 **현재 통합 웹 주소에서 접근 가능한 브라우저 데이터**. 이 기능을 설치해도 구형 사이트의 브라우저 데이터는 자동으로 옮겨지지 않습니다.

## 1. 이전 순서

1. **구형 사이트를 그대로 유지**하고, 각 사이트에서 제공하는 백업·내보내기 기능으로 원본을 먼저 내려받습니다.
2. YGO STUDIO → **데이터·관리 → 기존 사이트 데이터 이전**으로 이동합니다.
3. 원본 파일 여러 개를 선택합니다. 파일을 저장하기 전에 형식·자료 수·SHA-256·중복 여부를 검토합니다.
4. **정상 파일을 원본 그대로 보관**을 누릅니다. 이 동작은 새 브라우저 IndexedDB에 파일을 복사할 뿐 기존 앱의 데이터는 수정하지 않습니다.
5. **원본 전체 ZIP 내보내기**를 사용합니다. ZIP에 원본 바이트와 `검증목록.json`의 해시 목록이 함께 들어갑니다. PC 다운로드 폴더의 ZIP을 실제로 확인하세요.
6. 카드 렌더러 JSON·이미지 연구소 설정 JSON·공통 카드/덱 JSON·YDK는 **공통 메타 병합 검토**를 선택할 수 있습니다. 신규 카드·덱·중복·충돌 건수를 확인한 다음 **신규만 병합**합니다.
7. 카드 렌더러·이미지 연구소·AI 검증 관제실 등 **대상 도구에서 실제 자료가 열리는지** 확인합니다. 이를 사용자가 확인한 경우에만 '복원 확인 표시'를 누릅니다. 이 체크는 수동 확인 기록이며 앱의 자동 검증 결과가 아닙니다.
8. 모든 원본 및 작업 기록의 이전·복구·체크섬 검증을 마칠 때까지 구형 사이트의 배포와 저장소를 유지합니다.

## 2. 종류별 처리 기준

| 자료 | V2.1 처리 | 자동 반영 여부 |
|---|---|---|
| 녹투르나 CARD STUDIO 원장 JSON | 원본으로 보관, 카드·승인·이력 개수 표시 | 기존 원장 자동 교체 **안 함** |
| 외부 작업 문서 백업 JSON | 승인/검수 메모 보관 | 자동 교체 **안 함** |
| CARD MAKER 프로젝트 JSON | 일러스트 포함 원본 그대로 보관, 카드 메타만 신규 병합 가능 | 카드 렌더러 자체 프로젝트까지 자동 이전 **안 함** |
| ART LAB 설정 JSON | 카드 목록·설정 원본 그대로 보관, 카드 메타만 신규 병합 가능 | 프리셋/이미지 자동 이전 **안 함** |
| 공통 카드·덱 JSON / YDK | 신규 메타만 병합. 원래 보관함은 먼저 자동 스냅샷 | 기존 ID 원문 덮어쓰기 **안 함** |
| PSH 관제실 백업 JSON | 세션·결함·검증 기록 원본으로 보관 | 실전 성공 판정·원본 기록 덮어쓰기 **안 함** |
| DESIGN LAB 결과 CSV/JSON, CDB, Lua, ZIP, PNG/JPG/WebP, YRP/YRPX | SHA-256 원본 보관·ZIP 내보내기 | 엔진 실행/내부 추출/내용 자동 승인 **안 함** |
| 손상 JSON·YDK | 경고와 함께 등록 차단 | 허용 안 함 |

## 3. 보호 및 제약

- 저장 위치: 현재 YGO STUDIO 브라우저의 IndexedDB(`ygo-studio-migration-v1`). **클라우드 동기화가 아니므로 ZIP을 PC에 별도로 저장**해야 합니다.
- 파일당 최대 40MiB, 동시 선택 30개, 일괄 ZIP 내보내기 원본 총합 120MiB. 더 큰 파일은 기존 개별 백업으로 보관합니다.
- 비트 단위 원본 파일 바이트의 SHA-256을 사용합니다. 동일 해시 파일은 중복 보관을 생략합니다. 보관 후 재읽기 및 ZIP 생성 전 재검증합니다.
- 서로 다른 GitHub Pages URL의 localStorage/IndexedDB에는 브라우저 보안 정책상 직접 접근할 수 없습니다. 따라서 구형 사이트의 자료는 원래 사이트에서 별도로 다운로드해야 합니다.
- '현재 통합 사이트에 저장된 항목 빠른 백업'은 현 주소의 CARD STUDIO/렌더러/ART LAB/PSH/공통 보관함 데이터에 한정됩니다.
- 공통 카드 메타 병합은 이미지·효과 승인·검증·Lua·리플레이·자동 AI 대전 결과를 이전하거나 인증하는 작업이 아닙니다.
- CDB/Lua 프로그램 연동 파일명은 그대로 유지하며, 사람 관리용 ZIP·문서명은 한글 위주로 작성합니다.
- 기존 7개 원본 GitHub 저장소 및 AI 엔진의 소스 코드와 실행 환경을 변경하지 않습니다.

## 4. 종료 보류 대상

다음은 V2.1만으로 완료할 수 없어 기존 사이트를 **지금 폐쇄하면 안 되는 이유**입니다.

- 이미지 연구소 구형 사이트의 브라우저 프리셋/생성 기록 **전체 내보내기**가 완비되지 않았습니다. 생성 이미지 ZIP은 별도 수집해야 합니다.
- DESIGN LAB의 브라우저 IndexedDB 파일 자료실은 **자료별 내보내기/복원 검증**이 필요합니다.
- PSH 관제실의 JSON 기록은 보관할 수 있지만 통합 페이지에 **자동 덮어쓰기 없이 복원**하는 기능은 별도입니다.
- 카드 렌더러 이미지/프레임 등 프로젝트의 실사용 복원은 해당 도구의 원래 JSON 가져오기 기능으로 확인해야 합니다.
- 실제 EDOPro 대전 및 MSG16 교착은 별도 검증 과제입니다.
