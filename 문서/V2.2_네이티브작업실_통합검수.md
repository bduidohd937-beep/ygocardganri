# YGO STUDIO V2.2 — 실제 네이티브 작업실 통합

검수 기준: 2026-11-12. 이 패치는 **두 제작 도구의 화면·실행 방식을 통합**하는 단계다. 전체 원본 데이터/승인/실전 대전 기능의 자동 동기화를 의미하지 않는다.

## 이번 패치: iframe 없는 기능 실행

| 화면 | 기존 | V2.2 |
|---|---|---|
| 이미지 연구소 | 독립 HTML 웹앱을 iframe에 표시 | 기존 ART LAB V1.4 생성 엔진을 현재 YGO STUDIO 문서의 Shadow DOM 안에 마운트 |
| 카드 렌더러 | 별도 React 웹앱을 iframe에 표시 | 기존 DUELMIND CARD STUDIO를 재사용 가능한 React 컴포넌트로 분리하여 YGO STUDIO 안에 직접 마운트 |
| DESIGN LAB | 독립 정적 JS/HTML | **이번에는 기존 iframe 유지**. 후속 포팅 검수 필요 |
| PSH AI 관제실 | 독립 정적 HTML | **이번에는 기존 iframe 유지**. 실제 엔진 실행과 분리 |

- 메인 왼쪽 메뉴와 상단 프로젝트 선택기는 YGO STUDIO가 관리한다.
- 원래 카드 렌더러의 **테마·카드별 목록과 편집기**는 웹사이트 내비게이션이 아닌 실제 편집 기능이므로 보존한다.
- 카드 작업실의 프레임·토큰·고급 크롭·리소스 ZIP·PNG/JPG/ZIP 출력 기능을 유지한다.
- ART LAB의 CDB/CSV/TXT 입력, 배경·모티브 선택, 단일·일괄 ZIP 내보내기를 원본 엔진 기반으로 제공한다.
- Shadow DOM을 사용해 도구별 CSS가 YGO STUDIO의 메뉴와 카드/덱 화면에 영향을 주지 않도록 격리한다.
- ART LAB 오픈 SVG의 Game-icons 기여자 Lorc/Delapouite 및 CC BY 3.0 출처 링크를 화면에 유지한다.

## 구현 및 신뢰 경계

- 카드 렌더러 원본: `bduidohd937-beep/ygocardmaker`, 별도 `src/embed.tsx` 라이브러리. 독립 페이지 진입점 `src/standalone.tsx`도 그대로 배포.
- 통합 카드 렌더러는 `dist/modules/cardmaker/embed/cardmaker.js`를 현재 도메인에서 동적으로 읽어 실행한다. **새 탭/iframe 없음.**
- ART LAB 원본은 수정하지 않고 `scripts/build-native-artlab.py`가 `dist/modules/artlab/native.js`로 생성한다. `document.getElementById` 조회를 내부 작업실 영역으로 제한하고, 원본의 `asset-engine-native.js`로 오픈 SVG 경로를 현재 사이트에 맞춘다.
- 통합 컴포넌트: `src/NativeWorkspace.tsx`. React StrictMode에서도 취소된 로딩 응답이 다른 작업실의 DOM을 지우지 못하도록 취소 검사와 마운트 소유권 검사를 적용.
- 카드 렌더러는 페이지를 떠나기 직전에도 최신 프로젝트를 IndexedDB에 저장하도록 보완한다. 기존 자동 저장은 유지.
- P2 공통 카드·덱 보관함에서 선택한 카드의 이미지 연구소/카드 렌더러로 **명시 승인·동일 ID 중복 제외** 전송을 유지한다.
- 이미지 연구소 저장 키: `ygo-art-lab-v1.1`, 카드 렌더러 IndexedDB: `duelmind-card-studio`, 공통 카드 키: `ygo-studio-shared-catalog-v1`. 기존 저장 레코드는 변환/초기화하지 않는다.

## 검증 게이트

1. 카드 렌더러 독립 빌드·단위 테스트 및 embed 라이브러리 빌드.
2. 기존 YGO STUDIO 타입 검사·단위 테스트·기존 E2E 전부 통과.
3. 통합 Chromium에서 ART LAB 캔버스/카드 목록 동작 및 CARD MAKER의 토큰 프레임·리소스·크롭 기능 확인.
4. P2 공통 카드 ID 전달, YDK 메타 보존 및 기존 카드 충돌 방지 회귀.
5. GitHub Pages 배포 성공 확인.

## 아직 남은 단계

- DESIGN LAB과 PSH 관제실의 iframe 제거는 후속 UI 네이티브 포팅 범위.
- 양방향 완전 동기화, 출력 이미지 자동 역전송, 통합 백업/복원, EDOPro 실제 AI 경기 자동 실행은 **이번 패치 범위 아님**.
- 구형 독립 배포는 사용자별 데이터/이미지 백업 및 복원 검증 전에는 폐쇄하지 않는다.
- 실제 브라우저를 열어 고화질 출력·CDB 파싱·일괄 ZIP 용량 등을 추가 실사용 확인하는 것은 별도 품질 검증 과제.
